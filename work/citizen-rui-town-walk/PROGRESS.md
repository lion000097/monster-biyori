# 本編1.25.97候補　市民ルイの街歩き

- 対象バージョン　本編のモンスター全127種を反映した1.25.96を基準に、次の市民歩行をルイ1人で試作。
- 保存先　`preview/citizen-rui-town-walk` の `work/citizen-rui-town-walk/` に原寸PNG、組み込み用コード、このメモを保存。確認動画は `rui-town-walk.mp4`（18.32秒）。
- 完了事項　ルイの髪・眼鏡・ベスト・袖・靴を元絵の配色で4方向に描き分けた。各方向に静止と左右の踏み出しを用意。採用済みモンスターの移動距離・向き・静止の処理を共用。　実際の街マップを100%・1倍速で収録し、方向転換、立ち止まり、夜のこもれびハウスへの入室と朝の退室を確認した。
- 確認結果　64×64の12コマ。各方向の顔と後頭部、左右の腕と足、靴底の共通位置を原寸で確認。判定には保存済みの外見IDを使用する。　公開版1.25.96と確認版で、同じ市民が道路を歩いて就寝し、朝に入口へ戻る25秒を1/30秒刻みで比較。750回の移動座標、経路の残り、入退室の段階が一致した。確認版では各方向で3コマすべてが表示され、停止中は約1.2秒間、最後の向きの静止コマを維持。室内では非表示、出入口で再表示された。
- セーブ確認　通常版のChromiumでPC幅1200pxとスマホ幅390pxを検査。1.25.81の世界樹Lv30のセーブを両版で読み込み、再保存・再読み込み後の34項目が一致した。配置444件、市民60人、仲間60匹、おやすみ25匹、所持品や冒険進行を含む。名前を変えたルイにも同じ外見が適用された。
- 残作業　ルイの歩き方の採用確認。ほかの市民・旅人への展開と本編1.25.97の配布はその後。現在の本編公開版は1.25.96。
- 次の操作　確認動画でルイの見た目を確認。採用ならこの試作を基にほかの市民・旅人へ広げ、旧セーブと配布版を確認して公開する。確認版は `python work/citizen-rui-town-walk/build.py releases/1.25.96/game.html rui-preview.html` で再生成できる。
