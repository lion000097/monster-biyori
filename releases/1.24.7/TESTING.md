# Ver.1.24.7 検証記録

Chromiumの1366×900と390×844の表示領域で、1.24.6が作成したセーブを1.24.7に読み込んで操作した。テスト用のセーブキーを使い、普段の牧場とは独立して検証できる。

| 確認項目 | 確認結果 |
| --- | --- |
| 既存セーブ | 所持資源（ごはんの端数を含む）、モンスター、市民、施設、冒険、素材図鑑・在庫が一致。牧場名は「こもれび牧場」。 |
| 施設の向き | 設置中の4方向の循環・逆回転、向きボタン、移設の確定・キャンセルを確認。正面が道に接しない位置は拒否され、施設・資金は保持された。通常時と施設を選択しただけの状態ではズームが動いた。デスクトップの地図上でもホイールを送り、倍率100％のままおやつ畑が下向きから左向きに回転した。 |
| ごはん | 同条件で実際のゲーム時計を進め、畑と温室の定期生産を計測。市民の採集処理でも畑・温室の採集と温室での加算を照合し、得られる量がすべて1.24.6の90％であることを確認した。 |
| 市民と資源 | 「市民」から担当を変更して保存できた。5資源すべてで用途説明が開閉し、表示更新中も読み続けられた。キーボードのフォーカスとEscape、狭い画面でのボタン操作も確認した。 |
| 牧場名 | 前後の空白、空欄、20文字・21文字、絵文字、キャンセルを確認。保存した名前を再起動・手動バックアップ復元・JSON読込で再表示した。保存を拒否した場合の名前も照合した。 |
