# もんすたー日和 Ver.1.25.66

世界樹Lv9・11・12・14・30で、それぞれ2種類ずつ、計10種類の建物と装飾が解放されます。すべて4方向に設置できます。

| 世界樹 | 新しい建物・装飾 | できること |
| --- | --- | --- |
| Lv9 | おやつ備蓄庫・森の道しるべ | 備蓄庫でごはんの保存量と菜園の食事用取り置きが10〜20%増えます。道しるべは道の上にも飾れます。 |
| Lv11 | 森の資料室・旅人のお願い受付所 | 市民1人が働くと、資料室では研究費が3〜7%安くなります。受付所ではごはん・素材を自動で納品し、評判とキラキラを受け取れます。 |
| Lv12 | お宝みがき工房・きらめく水晶鉢 | 市民1人の勤務中、展示館と展示台のお宝の人気度が5〜10%上がります。水晶鉢は夜に光ります。 |
| Lv14 | 旅支度の工房・星見の望遠鏡 | 市民1人の勤務中、自動遠征の所要時間が3〜7%短くなります。望遠鏡のレンズには夜だけ星明かりが映ります。 |
| Lv30 | 世界樹の迎賓館・世界樹の記念門 | 迎賓館では市民1〜3人が特別な旅人を接客します。ごはんを使い、売上の75%を維持費に充てます。記念門の下には道を通せます。 |

6施設の強化上限はLv3です。4種類の装飾は世界樹の成長条件から外れます。お願いの納品には食事用の取り置きやSSR・UR素材を使いません。以前の牧場はそのまま続けられます。
