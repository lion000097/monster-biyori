# Ver.1.24.9 検証記録

Chromeで1366×900と390×844の両方を検証しました。前版と今回のゲームを同じブラウザに読み込み、検証専用のセーブを使いました。

| 項目 | 確認結果 |
| --- | --- |
| 旧セーブ | 1.24.8で保存した牧場名、日付・時刻、資源、仲間・色違い・市民、施設の位置と向き、編成・冒険、図鑑・素材在庫・お宝・絵はがき、解放区画が読み込み後に一致。 |
| 旅人の寄り道 | 買い物後に道を通って郵便局へ。施設内で保存して読み直しても会計・来客・投函は各1回で、牧場の外まで帰宅した。最初から道がつながらない場合、移動途中の道や目的の施設を撤去した場合も帰宅に切り替わった。 |
| 昼寝と追いかけっこ | 散歩中の仲間が自動で昼寝を開始して起床。寝姿の描画と選択範囲が一致し、試験中の座標・経験値・気力・絆は維持された。追いかけっこでは2匹が道を順に走って解散し、途中で相手がいなくなったときも散歩に戻った。 |

| 夏の蛍 | 夏の晴れた夜と深夜に蛍を描画。時間の進行で位置と明るさが変わり、同じ時刻の描画は一致した。日中・雨・ほかの季節の条件も確認。 |
| 戦闘中のお別れ | 手動編成・自動編成の両方で育成カルテの「お別れ」を操作。控えを手放すと戦闘の状態は同一で、出撃中の仲間を手放すと戦闘が終了した。 |
