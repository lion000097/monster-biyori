# Ver.1.24.8 検証記録

Chromiumの1366×900と390×844の両方で、1.24.7のゲームが作ったセーブを1.24.8に引き継いで確認しました。検証画面は専用のセーブを作成し、終了時に片付けます。

| 項目 | 確認した内容 |
| --- | --- |
| セーブ | 牧場名、所持資源、仲間・市民、施設の位置と向き、冒険、図鑑、素材在庫、お宝、出撃編成を照合。 |
| 建設費 | 全施設の一覧を旧版の価格と解放レベルから求めた金額と照合。とっくん広場は428Gで購入できず、429Gで建設できた。所持金と会計の支出が一致。初回無料、旧施設の強化費と回収計算、新施設の再読込と実際の65％返金も確認。 |
| 冒険 | 指定された2項目と遠征の例文を削除。遠征の行き先変更・停止・再開、お宝図鑑の表示を操作し、出撃・編成・ボス選択・次の解放先の表示を確認。 |
| 仲間 | 4段階の希少度、お気に入り、同じ希少度でレベルが異なる仲間、色違いを含む一覧で確認。並べ替え後の再描画、名前順への切替、保存された仲間と編成の順序を照合。 |
| 施設の出入り | こもれびハウスと旅の郵便局で、仲間・市民・旅人が4方向から入場・利用・退場する間の地図の描画順、仕事完了、入口への帰着を確認。上向きの家では屋根と仲間の不透明な画素が重なる場所のクリックが建物に当たった。 |
