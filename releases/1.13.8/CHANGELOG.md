# もんすたー日和 Ver.1.13.8

## 修正

- 一時停止中は、職員の作業・来客の会計・移動も時計や遠征と一緒に停止します。起動直後の最初のフレームにも適用します。
- タブやアプリを切り替えても、切り替える前に進めたゲーム内時間の端数を保持します。非表示中の時間を加算する仕様には変更していません。
- 自動遠征の選択欄と変更ログの番号を「1-1、2-1、3-1…」に統一しました。探検担当の効果は進行速度の上昇として正確に表示します。
- たまごのカード・上部案内・ヒントで、世界樹の上限、ハウスの定員、次の時間更新待ち、一時停止を同じ判定で表示します。

## バックアップ

- 手動6件、自動6件、復元前1件を独立して保持します。自動バックアップが手動保存や復元前の記録を消すことはありません。
- 手動の7件目は最も古い手動保存を更新します。復元・ファイル読み込みの直前には、未保存の進行も含めて復元前枠へ退避します。
- 保存容量が足りない場合は古い自動記録だけを減らして再試行し、保存できなければ既存のバックアップを保持します。
- 復元・読み込み後の保存に失敗した場合は成功扱いにせず、元の状態へ戻します。従来のセーブキー、旧バックアップ形式、更新前バックアップを継続して利用します。

## お気に入り・保護

- 仲間を選ぶと「お気に入り」「保護」のボタンが表示されます。
- お気に入りは並べ替え条件の中で先頭に表示され、登録時に自動で保護されます。
- お気に入りを外しても保護は残ります。保護解除は別操作で確認します。
- 保護中は「お別れ」を無効化し、処理本体でも保護を確認します。

## お宝図鑑

- 発見状況（すべて／未発見／発見済み）、入手先（すべて／通常／ボス限定）、レア度を組み合わせて絞り込めます。
- 表示件数と該当なしの案内を表示します。絞り込み条件はセーブに保存します。
- 既存のお宝ID、所持記録、ドット絵、入手方法表示を維持します。

## 検証

1.13.7を起動して生成したセーブを使い、仲間・職員・施設・お宝・資源・遠征進捗を引き継いで確認しました。
JSDOMと実キャンバスによるゲーム全体の統合テストでは、一時停止／再開、画面切り替え、表示の整合性、実際のボタン操作、フィルター、再読み込み、バックアップの保持、容量不足、復元失敗時の復旧、ファイル読み込みを確認しています。
停止・時間・表示の限定テスト4群と、バックアップ・復元の限定テスト18件も通過しました。全スクリプトの構文、既存画像データの一致、配信ファイルのSHA-256を確認しています。

統合テストの再実行にはNode.jsと次の検証用依存が必要です（ゲームの実行には不要）。

```sh
npm install --no-save jsdom@26.1.0 @napi-rs/canvas@0.1.100
node tests/v1.13.8-regression.cjs
```

検証環境の制限により、公開前のローカルHTMLをブラウザで直接開く確認は行えていません。実ブラウザの長時間プレイや、すべての利用者のセーブを網羅した検証ではありません。
