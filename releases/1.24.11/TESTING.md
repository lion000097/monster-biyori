# Ver.1.24.11 動作確認

1.24.10で作成したセーブを使い、1366×900と390×844のChromeで同じゲーム本体を検証した。

| 項目 | 確認結果 |
| --- | --- |
| 既存セーブ | 牧場名、資源、研究レベル、仲間と市民、施設と道、編成、冒険、図鑑、素材、宝物、絵はがき、区画を引き継いだ。 |
| 研究 | 全6種類のLv.0・Lv.3で価格と効果の表示を確認。ゴールド・キラキラのいずれかが不足すると購入できず、ちょうど足りる場合は表示額を支払い、研究レベルと評判が上がった。畑の収穫にも新しい効果が反映された。 |
| ボス | 1-5での敗北後の初撃破で330G。手動再戦、連続周回、保存再開後の周回、戦闘中に周回を止めて勝利した場合は0G。財布と両方の収入記録、勝利の表示で照合。通常戦・通常戦の再訪・別エリアの初回報酬も確認。 |
| 屋内就寝 | ハウスと宿を4方向で検証。到着前は見え、入室後はキャラクター・影・タップ対象が消えた。通常表示と縮小表示の両方で、建物ごとに屋根のZzが1つ出た。同室の仲間が全員起きると消え、仲間は入口に戻った。 |
| 就寝中の再開 | 仲間と旅人の残り休憩時間、宿代の支払いを引き継いだ。宿の撤去、ハウスの回転、別棟の工事、屋外の昼寝、お世話中の市民も検証した。 |
