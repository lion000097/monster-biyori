# Ver.1.24.3 検証記録

## 修正箇所の回帰確認

次の専用テストを実行し、1.24.3で成功することを確認しました。

- `tests/v1.24.3-party.cjs` — 戦闘中の編成変更、残HP割合、手動から自動編成への復帰、3体上限、敵HP・ラウンド・保存内容・HPバーの維持。
- `tests/v1.24.3-save-validation.cjs` — 不正な実ファイルのインポート18ケース、現在の牧場・セーブ・バックアップの保持、復元と起動時の検証、正常な1.24.2セーブ、旧形式の任意項目、職員の疲労0。
- `tests/v1.24.3-selects.cjs` — 仲間・職員の並べ替え後の自動更新、消えた選択欄のロック解除、操作中の図鑑・遠征先の選択欄保持。
- `tests/v1.24.3-terrain.cjs` — 全5地形ツールのEsc終了、有料タイルのドラッグ中止・保存、ポインターキャプチャ解除、終了後の消費防止、編集再開。

修正前の1.24.2でも再現確認を行い、今回の修正が対象の不具合を解消することを確認しています。

## 実行方法と確認範囲

専用テストはNode.jsと `jsdom`、`@napi-rs/canvas` を使用します。`MONSTER_QA_JSDOM` でjsdomのインストール先を指定できます。

```sh
node tests/v1.24.3-party.cjs
node tests/v1.24.3-save-validation.cjs
node tests/v1.24.3-selects.cjs
node tests/v1.24.3-terrain.cjs
```

`tests/v1.24.3-browser.cjs` はPlaywrightとChromiumでPC幅・390px幅の操作を確認するためのテストです。この作業環境ではChromiumのソケット作成が制限され、実行権限の拡張も承認ポリシーで拒否されたため、このローカル実ブラウザテストは未実行です。Windowsの実機ランチャー動作とiPhone実機での操作も確認対象外です。
