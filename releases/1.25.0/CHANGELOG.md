# もんすたー日和 1.25.0「森の庭だより」

「施設」の「観光・装飾」に、4種類の庭飾りが加わりました。すべて草地・土の道・石畳に設置でき、下・左・上・右に回すと向きに合わせて絵が変わります。

| 世界樹 | 飾り | 牧場で見られること |
| --- | --- | --- |
| Lv.1 | きのこの腰かけ | 小柄な仲間が腰かけて、足をぶらぶらさせます。 |
| Lv.2 | ちいさな鳥の水浴び鉢 | 日中、水浴びに訪れた小鳥を近くの仲間が見守ります。 |
| Lv.4 | つるバラのアーチ | 仲間が下を通れます。春には花びら、秋には赤い葉が舞います。 |
| Lv.5 | どんぐりの屋台飾り | 秋に仲間が気に入った木の実を手に取り、木箱に戻します。 |

既存の牧場から続けて遊べます。試作版で押し花のランタンを置いていた場合は、読み込み時に建設費を返します。
