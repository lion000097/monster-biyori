# もんすたー日和 1.25.0「森の庭だより」

施設一覧の「観光・装飾」に、次の5種類が加わりました。仲間のしぐさは自動で始まります。

| 世界樹 | 飾り | 牧場で見られること |
| --- | --- | --- |
| Lv.1 | きのこの腰かけ | 木のベンチより小さなきのこ。小柄な仲間が腰かけて、足をぶらぶらさせます。 |
| Lv.2 | ちいさな鳥の水浴び鉢 | 日中、小鳥が浅い石鉢に降りて羽を洗います。近くの仲間は足を止めてそっと見守ります。 |
| Lv.3 | 押し花のランタン | 昼はすりガラスに押し花が透け、夜は小さな明かりが足元に花の影を映します。 |
| Lv.4 | つるバラのアーチ | 道にかけると仲間が下を通れます。春は花びら、秋は赤い葉が舞い落ちます。 |
| Lv.5 | どんぐりの屋台飾り | 秋になると仲間が木箱をのぞき、気に入った実を手に取って戻します。売買や補充はありません。 |

5種類とも草地、土の道、石畳に設置できます。道を歩く仲間のそばに置くと、しぐさを間近で見られます。既存の牧場の続きから遊べます。

同じ版で準備されていた、まものの露天風呂の原画修正も反映しました。左・上向きに木の段差、桶とタオルを描き足しています。
