# もんすたー日和 1.25.0 動作確認

Chrome の幅1366pxと390pxで、ゲームを読み込み、次の動作を確認しました。検証に使った牧場はプレイヤーのセーブから独立しています。

- 1.24.31で保存した牧場を1.25.0で開き、資源、世界樹、既存施設の位置と向き、道、装備を持つ仲間や市民、素材、お宝、注文、遠征進行を照合。
- 施設タブから5種類を選択。各解放Lv、建設費、4方向の回転、草地への移設、土の道・石畳の敷き替え、建物の重なり防止、再保存・再読込、回収後の地面を確認。
- ほかの施設の唯一の入口、および通行中の仲間の真上にアーチを設置。通り道・歩行者・入口を保ち、仲間が経路の反対側まで通り抜けることを確認。
- 小鳥の飛来、着水、水浴び、水切り、離陸と2匹の見守りを確認。きのこでは小柄な仲間の着席・足振り・退席、大型の仲間の除外、中途保存・一時停止を確認。
- 春と秋の落下物、夏と冬の非表示、ランタンの昼夜と足元の影、秋の屋台の手に取る・戻す動作を確認。見物の前後で所持金・素材・お宝・売上は一致。演出中の移設も確認。

検証は `tests/v1.25.0-garden.html` の「検証を開始」から再実行できます。紹介画像は、この版の牧場を春・夏・秋の昼夜に撮影したものです。

同時に保存されていた露天風呂の原画修正を統合。下・右向きが従来の画像と同一、左・上向きが新しい原画であること、ゲーム内と同梱PNGが一致することを照合。全4方向で描画・入浴・退出を確認しました。
