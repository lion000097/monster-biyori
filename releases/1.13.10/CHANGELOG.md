# もんすたー日和 Ver.1.13.10

## 世界樹と職員

職員とモンスターの配置枠が同じペースで増えるようになりました。枠はそれぞれ独立していて、世界樹Lv.20では職員45人とモンスター45体を同時に配置できます。職員の雇用枠は世界樹のレベルで決まります。こもれびハウスでは、これまでどおり仲間が休み、お世話担当の職員が働きます。

| 世界樹 | 職員の上限 | モンスターの上限 |
| --- | ---: | ---: |
| Lv.1 | 4人 | 4体 |
| Lv.5 | 12人 | 12体 |
| Lv.10 | 23人 | 23体 |
| Lv.15 | 34人 | 34体 |
| Lv.20 | 45人 | 45体 |

## 素材図鑑

「図鑑 → 素材」は、アイコンの下に素材名とレア度を横書きで表示します。図鑑の幅に合わせて1～3列に切り替わります。図鑑から在庫数の表示を外しました。素材を使い切っても発見記録は残ります。

素材牧場で生産できる素材が24種から30種に増えました。生産1回につき、次の確率でレア度を抽選します。当選すると、そのレア度の中から1種類を均等に選びます。生産量・モンスターのレベル・特技によるSSR・URの確率の変動はありません。

| レア度 | 生産1回あたりの確率 | 今回追加した素材 |
| --- | ---: | --- |
| SSR | 0.001%（10万分の1） | 月虹のまゆ糸、星蛍の光粉、霜竜の銀鱗 |
| UR | 0.0002%（50万分の1） | 世界樹の星しずく、不死鳥の風切羽、空鯨の虹真珠 |

以前からある「七色の星くず」「世界樹の琥珀蜜」も含めると、今回のUR抽選は全5種です。Ver.1.13.9で集めた素材、在庫、既読の状態、雇った職員は引き継がれます。
