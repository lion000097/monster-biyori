# Ver.1.24.6 検証記録

## 1.24.5からの引き継ぎ

Chromiumで1.24.5の牧場を保存し、同じオリジンの1.24.6で開いた。PC幅1366×900はマウス、スマートフォン幅390×844はタッチで操作した。

| 確認した操作 | 結果 |
| --- | --- |
| 旧セーブの読込 | 牧場の資源、施設、仲間、職員、編成、冒険進行、展示中のお宝が一致。旧素材30種の在庫・発見記録を保持し、新規12種の在庫は0から開始。 |
| 素材牧場と図鑑 | 生産時の抽選を指定して新規12種をすべて入手。No.31〜42の絵・レアリティと、NEW・未発見の絞り込みを確認。 |
| お宝の展示 | 地図と「施設」から選択画面を開き、入れ替え・取り外し・再設置ができた。ほかの台に展示中のお宝は選択不可。 |
| 再起動 | 再保存した在庫、発見記録、展示品が一致。両画面幅で実行時エラーは0件。 |
