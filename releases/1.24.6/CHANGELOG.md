# もんすたー日和 Ver.1.24.6

素材図鑑が30種から42種になりました。追加の12種は素材牧場で生産できます。それぞれに専用のドット絵があります。

| レアリティ | 新しい素材 |
| --- | --- |
| N | こならのどんぐり、白樺の小枝、まきばの野いちご、金色の麦穂 |
| R | 鈴咲き草、夕焼けきのこ、潮風の巻き貝、ほたる苔 |
| SR | 霧鹿の若角、流星の磁鉄鉱、水鏡の睡蓮、星蜂の蜜ろう |

地図で「ボスのお宝展示台」を選ぶと、向きボタンの横に「お宝を設置」が表示されます。「施設」タブの展示台詳細からも、所持しているお宝の絵を見ながら設置・入れ替え・取り外しができます。

1.24.5のセーブをそのまま引き継げます。素材の在庫や発見記録、展示中のお宝も引き継ぎます。
