# 1.25.81　おまかせ観察カメラとプレイ時間

- 牧場の地図に「おまかせ観察カメラ」を追加しました。ONにすると、ピクニックや演奏会など、観察手帳に載る12種類の場面が起きた場所へ視点が移ります。一度発見した場面も見守れます。
- 建築・地形編集や仲間のおさんぽカメラを使っている間は、自動移動を一時停止します。手で地図を動かしたあとも、しばらくその場所を眺められます。観察カメラのON・OFFは牧場ごとに保存されます。
- 「牧場のようす」に累計プレイ時間を追加しました。図鑑や一時停止を含め、ゲームを画面に表示している実時間を時・分・秒で表示します。4倍速でも実時間1分は1分です。閉じている間や別タブを表示している間は計測を休みます。
- 以前の牧場はそのまま引き継げます。旧セーブのプレイ時間は、この版で初めて牧場を開いたときから計測します。
