# 世界樹Lv20・1倍速の比較

同じシードと同じ管理間隔で1.25.4と1.25.5候補のゲーム本体を実行。開始は新規牧場（世界樹正面の初期道路を含む）。無料の店と素材牧場を建て、実際の建設、強化、道路敷設、土地購入、雇用、勤務、販売、納品、研究、遠征と自動進軍を使用。確認は毎20・25・30分、手動特訓とボス周回なし。表示・描画・通知・セーブだけ省略。候補のまとめ強化と同じ費用・進行処理を、既存の1段階強化で積み上げる。UIの操作にかかる秒数は含まない。比較の条件は対象プレイヤーの保証ではない。

ヒアリング後の新しい目標は、1倍速の画面表示中に世界樹Lv20まで55～65時間を目安とするもの。Lv10は8～10時間、Lv15は25～30時間の目安。Lv20の到達で計測を止め、冒険の10-5は同じ計測区間で撃破した場合にだけ記録。10-5未達をクリア時間とはしない。

検証スクリプトを本リポジトリの `tests/simulate-world-tree-1.25.5.cjs` に置いた場合の例（`jsdom@26` と `@napi-rs/canvas` が必要）:

```sh
node tests/simulate-world-tree-1.25.5.cjs /path/game.html 7 68 25 /tmp/result-seed7.json
```

引数は、計測するHTML、シード（カンマ区切り可）、打ち切り時間、1倍速での確認間隔（分）、保存先。任意の `--continue-adventure` で、Lv20以降も上限まで10-5撃破を観測します。結果の `complete` は両目標を達成した場合だけ true となり、世界樹Lv20の達成は `tree20Seconds` を参照してください。時刻は100ms刻み。Lv10/Lv15は保存された時計の粒度（16秒）を分に丸めています。

## 実測結果

| 確認の間隔 / seed | 1.25.4 Lv20 | 1.25.5 Lv10 | 1.25.5 Lv15 | 1.25.5 Lv20 |
|---|---:|---:|---:|---:|
| 20分 / 23 | 42:00 | 08:40 | 25:40 | 57:00 |
| 25分 / 7 | 43:20 | 09:10 | 26:40 | 59:10 |
| 30分 / 91 | 44:30 | 09:30 | 27:00 | 60:00 |

単位は1倍速での累計時間:分。3試行の範囲は57〜60時間、中央値は59時間10分。10-5 はいずれの試行でもこの観測区間には未達。

計測した 1.25.5 候補 SHA-256: `32a27e31dbec1e3445e676245b299c0b9cb001edccd6f8f288b6ec9e4dc5e51a`。開発版の最終候補 SHA-256: `47b4ebbd72692cb662b9cd42f890864ed8457818f555cef81cd8e3a69fd5b906`。2つの差はまとめ強化の金額の省略表示を正確な桁区切りに変えたことだけで、見積りや実際の進行処理は一致。
