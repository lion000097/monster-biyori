# Ver.1.24.10 動作確認

Chromeの1366×900と390×844の各画面幅で、1.24.9で作った検証用セーブを読み込み、牧場の更新と描画を実行しました。

| 項目 | 確認結果 |
| --- | --- |
| 旧セーブ | 牧場名・日付・時刻・資源、仲間と性格・色違い・絆・気力、預かり所、市民・施設・道、編成・冒険、図鑑・素材・宝物・絵はがき・解放区画が引き継がれた。 |
| 雨の道 | 通常表示と縮小表示で、雨の道に水たまりが現れ、晴れた日に消えた。実際の描画色を照合した。 |
| 性格と雨宿り | 全5性格で行動の分岐を確認。飛び越える仲間は水たまりの向こうの道に、飛び込む仲間は水たまりに着地。雨宿り中の仲間が近くのしぶきに反応した。ジャンプ中の描画と選択範囲も一致。 |
| 誘って走る | 1匹が隣の道まで近づいて相手側に身を乗り出し、先に走る。相手がその場で一拍待ち、道を追ってそれぞれ別のマスで散歩に戻った。モンスターの処理順を入れ替えても同じ。 |
| 中断と再開 | 途中で建物・道・相手がいなくなっても解散し、素材の仕事が発生すればそちらを優先。雨の日のジャンプ中と追いかけっこの開始直後に保存して再読込し、仲間が道に復帰した。一時停止中は誘いの進行も停止。 |
