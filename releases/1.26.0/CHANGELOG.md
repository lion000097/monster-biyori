# 1.26.0 — 世界樹とにぎわう街

世界樹の上限をLv30へ拡張。新しい建物15種類をLv15〜29で1種類ずつ解放します。すべて4方向で配置でき、入口までの道と敷地内の往復を使います。

- シャボン玉、おえかき、雨宿り、4匹からの音楽会、夜光きのこ、劇場、水族館、レストラン、パン工房、交易所、集会所、案内所、おまつり広場を追加。
- 星あかりの長屋は市民5人・モンスター5匹まで。Lv21／25／30で1軒ずつ、最大3軒。帰宅人数に応じて窓が灯ります。
- まかない菜園はLv22／27で1か所ずつ。収穫は住人の食事1日分まで自動で取り置き。同じ面積のおやつ畑より生産効率を高めず、収入補正もありません。
- モンスター・市民の上限はそれぞれLv21で50、Lv25で55、Lv30で60。世界樹はLv25・30で樹冠が成長します。
- 新施設で世界樹の成長条件に入るのは、強化ありの6種類のみ。新施設の強化上限は解放時Lv2、世界樹が2レベル育つごとに1段階、最大Lv5です。
- 収益は通常旅人の実際の来店でのみ発生。レストラン最大4人、パン工房2人、案内所1人が自動勤務します。大型施設に日々の運営費を設定しました。
- 既存施設のLv20以降の設置上限と、通常旅人14人＋観光専用旅人の仕組みは維持します。
