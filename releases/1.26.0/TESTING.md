# 1.26.0 の検証

Chromiumによる `node tests/town-1260.cjs` と、同テストをランチャーHTMLに対して実施し、両方で合格しました。

- 15種類×4方向の配置、寸法、入口、建築価格。
- 世界樹Lv20からLv30の各成長条件を実際に満たして成長。強化なし施設が必須条件に入らないこと、全必要軒数と強化段階がその時点で到達可能なこと。
- 市民・モンスター上限50／55／60と既存施設の設置上限維持。
- 菜園の同面積生産量、食事用取り置き、消費優先、余剰、保存復元。
- 商業施設への入場、滞在中の非表示、退出と道への復帰。
- レストラン4人、パン工房2人、案内所1人の勤務上限。営業時間、料理・材料消費、購入重複防止、売上上限到達時の資源保護、観光枠から収入が生まれないこと。
- 維持費は1日1回、資金不足時に休業。
- 音楽堂は3匹では開催せず、4匹目が実際に入場してから開催。移設で利用者を解放。
- 長屋の市民5人＋モンスター5匹の独立した定員、10人分の帰宅、就寝中の保存復元。
- 案内所から新施設への実際の移動予約。
- 通常の移動処理と組み合わせた動作、利用中の住人が保存から消えないこと。
- 旧版1.25.59で実際に保存したデータを新版に読み込み、Lv20・所持金・モンスターと市民のIDが維持されること。
- PC幅と390pxのスマホ幅で起動・建築一覧・横はみ出し。Lv25・30の世界樹と新建物の原寸画像を確認。

Windowsランチャー・iPhone実機は未検証です。全施設が密集した最大人数の長時間プレイと、実プレイでの経済バランスは追加確認の余地があります。自動テスト用フックは配布HTMLに含めません。

公開前検査 `python tools/release_preflight.py --root .` に合格。軽量HTMLは4 MiB以下、manifestのSHA-256、ZIPのCRCとゲームHTML一致を確認しました。
