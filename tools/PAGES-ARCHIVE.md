# Pages archive maintenance
GitHub Pages remains on the existing source. The explicit exclusions in `_config.yml` remove old game ZIPs from the Pages build only. All files and commit history remain in Git; new release ZIPs are public on Pages until explicitly archived. Do not change `latest.json`, the current game or launcher HTML, artwork, saves, or the original game URL for archive maintenance.
At initial cutover, 96 historical ZIPs were downloaded from the immutable commit `49cb9f2b610d80982b2f8dbd16cb61b3f58ff1f0` and verified against the Git blob SHA-1 and the ZIP CRC; the five latest ZIPs stayed at their original URLs. The archive index is `archive.html`. Before adding a new exclusion verify the new pinned download similarly and update its entry in both `archive.html` and `404.html`. The latter offers a download link to visitors opening an old URL in a browser; original archived URLs still report HTTP 404 to direct download clients.
Check the Pages workflow and live root game, manifest and latest ZIP after each change. Keep the launcher preflight separate. If exclusions fail or affect current game assets, revert only the archive config/pages (never rewrite public history).
